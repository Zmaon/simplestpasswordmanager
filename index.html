Are you using the same password everywhere? Or do you just change it a little bit from service to service? Then The Simple Password Manager is made for you.

Using the same password on many services is really dangerous. It means that if one of your accounts gets compromised, malicous people will be able to get access to all your other accounts. If you think that security breaches are rare, or concern only small services, just have a look at this list.

Using the The Simple Password Manager you'll be able to generate strong passwords very easily, without using a full featured password manager software.

How does it work?

Think about a personal and easy to remember master passphrase, for example (do NOT use this one!): "My cat eats pizza on Tuesdays".

Type it in the master passphrase field above, type the name of the website in the website field (for example github) and voilà! Your password is generated. The next time that you require this password, just re-type the same passphrase and website, it will give you the same password.

Be unpredictable!

Try to figure out a passphrase that is not easy to guess! For example you can use lowercase, uppercase and special characters, slang or words you made up. Using another language than english is a good idea too!

Do not write your passphrase down!

If someone gets your passphrase, he could easily figure out all of your passwords.

FAQ

How is it better than just using my passphrase at Github or Google?

If one of the services you are using gets hacked (which happens regularly) and your password is stolen, or if employees get access to your password, they would directly know the password you use everywhere else. With The simple password manager, each website gets a different password, and the only way to go back from one of them to your passphrase is to guess it. Version 2 makes every single guess deliberately slow (600,000 rounds of PBKDF2), so a passphrase that is hard to guess stays out of reach.

What's the difference between v1 and v2?

v1 generated passwords with a single SHA-256 hash, which is very fast to compute: someone who got one of your v1 passwords could try billions of passphrases per second until they found yours. v2 uses a slow key derivation function (PBKDF2), uses the website as a separate input, and always includes a lowercase letter, an uppercase letter, a digit and a symbol.
v1 and v2 give different passwords for the same passphrase. v1 is still available so that you can log in with your old passwords and change them to v2 ones.

Is my password stored anywhere?

No. In fact, nothing is sent to the web, everything happens locally in your browser. This is really easy for you to monitor using the developer console of your browser, and checking that no network connection happens when you type your passphrase. The only things your browser remembers are whether you chose v1 or v2, and light or dark theme.

What if you get hacked?

It's true that if a malicious hacker succeeded in hacking our server, he could change the script to make it send the passphrases somewhere.
To prevent that, we are regularly monitoring our server. We also encourage all the users of the service to check that no network connection happens when they type a passphrase. This is really easy to see using the developer console of your browser.

What if this website stops existing?

The "recipe" that transforms your passphrase into a password is not a secret, and is actually quite simple. You can see it by checking the github repository.
In fact, any geek could clone the repository and start a copy of this service in a few minutes.
